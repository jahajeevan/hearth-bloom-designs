# Hearth & Bloom Designs

A contemporary interior-design portfolio website focused on services, project work, design process, before-and-after stories, and client testimonials.

## Technology

- React and TypeScript
- TanStack Start and Vite
- Tailwind CSS
- Framer Motion

## Run locally

```bash
bun install
bun run dev
```

Use `bun run build` to create a production build.
